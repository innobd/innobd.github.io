Lab rules 1

Dropbox 데이터 관리 원칙

Dropbox data management principles

실험 데이터는 얻은 당일, Dropbox 프로젝트 폴더에서 바로 저장하고 분석합니다. 파일을 메일이나 Slack으로 주고받지 않습니다.

Experimental data is saved and analyzed in the Dropbox project folder on the day it is obtained. Files are not passed around by email or Slack.

출처: 260709_폴더 파일명 데이터 분석 공지.pptx (PI 공지)Source: 260709 folder, file name and data analysis notice (PI announcement)웹 정리: 2026-10-15Web version: 2026-10-15

1. Dropbox에서 바로 작업한다

데이터는 즉시 Dropbox 프로젝트 폴더에 업로드하고, 분석도 Dropbox 상에서 바로 진행합니다. Slack이나 메일로 파일을 공유하는 것은 지양합니다.
이렇게 하지 않기
  • '여기 데이터 분석 파일 송부드립니다'
  • '논문 수정본 송부드립니다'
이렇게 하기
  • '첨부드리는 그림처럼 데이터가 나왔고, ~로 생각됩니다. 파일은 ~폴더에 있습니다'
  • '최신 논문 수정본은 프로젝트의 ~~260709c.docx 이름으로 저장해놓았습니다'

2. 데이터 획득, 분석, 정리는 한 세트다

'DATA(raw data)를 획득하고 분석(GraphPad/FlowJo) 및 정리(.pptx)까지 진행하는 것'이 실험의 기본입니다. 실험 계획을 세울 때부터 데이터 획득, 분석, 정리까지 한 세트로 계획합니다.

데이터를 얻은 당일, 해당 실험 폴더 안에 raw data와 분석 파일(GraphPad, PPTX 등)을 업데이트하는 것이 의무입니다.

3. 절대 피해야 할 상황

  • 실험은 진행했는데 아직 데이터를 export하지 못했습니다
  • 분석했는데 아직 Dropbox에 업로드하지 못했습니다
  • 파일이 어디 있는지 모르겠습니다, 아마 제 컴퓨터에 있는 것 같습니다
  • 데이터는 얻었는데 아직 분석은 더 해봐야 할 것 같습니다
  • 폴더 이름이 임의로 되어 있음
  • 7월 4일에 얻은 데이터가 7월 6일에 업로드됨
  • 그래프는 이렇게 나왔는데 분석한 파일이 어디 있는지 모르겠습니다
  • PPTX에 GraphPad 파일이 아닌 그림으로 그래프가 붙여넣기 되어 있음

폴더 구조와 파일명 규칙은 프로젝트 폴더와 실험 폴더 구조를, 데이터 PPT 작성 규칙은 InnoBD 데이터 PPT 작성 규칙을 참고하세요.

1. Work directly in Dropbox

Upload data to the Dropbox project folder immediately and run the analysis there as well. Avoid sharing files through Slack or email.
Not like this
  • 'Here is the data analysis file.'
  • 'Here is the revised manuscript.'
Like this
  • 'The data came out as in the attached figure and I think it means ~. The file is in the ~ folder.'
  • 'The latest manuscript revision is saved in the project folder as ~~260709c.docx.'

2. Acquire, analyze and summarize as one unit

An experiment means acquiring the raw data, analyzing it (GraphPad/FlowJo) and summarizing it (.pptx). Plan all three steps together from the start.

On the day data is obtained, the raw data and the analysis files (GraphPad, PPTX, etc.) must be updated inside that experiment folder.

3. Situations to avoid

  • 'I ran the experiment but have not exported the data yet.'
  • 'I analyzed it but have not uploaded it to Dropbox yet.'
  • 'I am not sure where the file is. Probably on my computer.'
  • 'I have the data but need to analyze it more.'
  • Folder named arbitrarily
  • Data obtained on July 4 uploaded on July 6
  • 'The graph looks like this but I do not know where the analysis file is.'
  • Graph pasted into the PPTX as a picture instead of the GraphPad file

See Project and experiment folder structure for folder and file naming, and InnoBD data PPT rules for slide conventions.
