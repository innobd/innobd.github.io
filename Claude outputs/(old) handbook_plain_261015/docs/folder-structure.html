Lab rules 2

프로젝트 폴더와 실험 폴더 구조

Project and experiment folder structure

프로젝트 폴더는 PI가 만들고, 구조와 파일명은 모든 프로젝트에서 같은 방식으로 유지합니다.

The PI creates each project folder. Its structure and file names stay the same across all projects.

출처: 260709 공지, 260722 실험 폴더 정리 공지 (PI 공지)Source: 260709 and 260722 PI announcements웹 정리: 2026-10-15Web version: 2026-10-15

1. 프로젝트 폴더

프로젝트를 시작하면 PI가 Dropbox 프로젝트 폴더를 생성하고 1st author와 실험에 참여하는 co-author를 초대합니다. 폴더 구성과 파일명을 일관성 있게 유지하고, 기본 폴더 외에 필요한 폴더는 추가하되 최소한으로 유지합니다.

프로젝트 폴더/ ├── 1. DATA ├── 2. References ├── 3. Protocols ├── 4. Meeting files ├── Project_Discussion.pptx ├── Project_Figure.pptx └── Project_manuscript.docx
2026-07-22 공지에서는 '최상위 폴더는 아래 5개만 남기고, 다른 폴더는 파일을 재정리한 뒤 삭제'하라고 안내했습니다. 다만 그 5개 폴더의 이름은 원본 슬라이드에 그림으로 들어 있어 텍스트로 확인되지 않았습니다. 위 구성(260709 공지 기준)과 차이가 있으면 PI에게 확인하세요.

2. 개별 실험 폴더

실험마다 폴더를 하나씩 만듭니다. 실패한 실험과 성공한 실험 모두 포함하며, 특별한 이유가 없다면 여러 실험을 하나의 폴더에 넣지 않습니다. 1. DATA 폴더 최상단에 상위/하위 폴더 예시가 있으니 참고합니다.

개별 실험 폴더 이름: YYMMDD_실험자_실험키워드
예: 260722_LTJ_cGAMP_0.1-1uM optimization
YYMMDD_실험자_실험키워드/ ├── Raw data/ 측정한 원 데이터 (*.fcs, *.xlsx 등) ├── (실험명).pptx 파일명 = 실험명. 분석 결과와 랩노트 내용 기재 ├── GraphPad 파일 그래프를 그린 파일 ├── (필요시) FlowJo FACS 분석 파일 └── (필요시) Excel 통계분석 등 진행 파일

PowerPoint 파일은 랩노트 역할을 합니다. 데이터를 얻은 당일에 raw data 업로드, 분석, 결과 discussion까지 완성하고, 모든 작업은 Dropbox 상에서 바로 진행하는 것을 원칙으로 합니다.

PPT 안에 어떤 내용을 어떤 순서로 쓰는지는 InnoBD 데이터 PPT 작성 규칙에 있습니다.

1. Project folder

When a project starts, the PI creates the Dropbox project folder and invites the first author and the co-authors taking part in the experiments. Keep the folder structure and file names consistent. Add folders beyond the defaults only when needed, and keep them to a minimum.

Project folder/ ├── 1. DATA ├── 2. References ├── 3. Protocols ├── 4. Meeting files ├── Project_Discussion.pptx ├── Project_Figure.pptx └── Project_manuscript.docx
The 2026-07-22 notice asked members to keep only five top-level folders and to delete the rest after moving files. The names of those five folders are in an image in the original slide and could not be extracted as text. If they differ from the list above (from the 260709 notice), check with the PI.

2. Individual experiment folder

Make one folder per experiment, for failed and successful experiments alike. Do not put several experiments in one folder without a specific reason. Example parent and child folders are at the top of 1. DATA.

Experiment folder name: YYMMDD_experimenter_keyword
Example: 260722_LTJ_cGAMP_0.1-1uM optimization
YYMMDD_experimenter_keyword/ ├── Raw data/ Measured raw data (*.fcs, *.xlsx, etc.) ├── (experiment).pptx File name = experiment name. Analysis results and lab-note content ├── GraphPad file The file the graphs were drawn in ├── (if needed) FlowJo FACS analysis file └── (if needed) Excel Statistics and similar work

The PowerPoint file serves as the lab notebook. On the day data is obtained, complete the raw data upload, the analysis and the result discussion. All work is done directly in Dropbox.

What goes into the PPT and in what order is described in InnoBD data PPT rules.
